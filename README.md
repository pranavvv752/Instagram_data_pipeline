📊 Instagram Engagement Analysis (Medallion Architecture)
🚀 Project Overview

This project analyzes Instagram post engagement using a Medallion Architecture (Bronze, Silver, Gold) built on Databricks.

🏗 Architecture
Bronze Layer: Raw data ingestion
Silver Layer: Data cleaning & transformation
Gold Layer: Aggregated insights (best posting time)
📈 Key Insights
Best posting time based on engagement
Day-wise performance trends
Hourly engagement heatmap (Power BI)
🛠 Tech Stack
PySpark (Databricks)
Delta Lake
